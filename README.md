# PALOMITOPTY — GitHub Pages

Esta versión está preparada para subir directamente a GitHub Pages.

## Archivos en la raíz

```text
index.html
styles.css
script.js
palomitopty-logo.webp
.nojekyll
README.md
```

**No existe una carpeta `assets`.** El logo está directamente en la raíz.

## Publicar

1. Crea un repositorio nuevo en GitHub.
2. Sube TODOS estos archivos directamente a la raíz del repositorio.
3. Entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Branch: `main`
6. Folder: `/ (root)`
7. Pulsa **Save**.

El `index.html` utiliza exactamente:

```html
<img src="palomitopty-logo.webp" alt="Logo PALOMITOPTY">
```
