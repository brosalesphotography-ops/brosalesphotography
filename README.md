## Estructura

Todos los archivos están directamente en la raíz. NO existe carpeta `assets`.

```text
index.html
styles.css
script.js
palomitopty-logo.webp
.nojekyll
README.md
```

## Publicar en GitHub Pages

1. Crea un repositorio.
2. Sube todos los archivos anteriores directamente a la raíz.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: / (root).
7. Save.

El logo se carga directamente como:

`palomitopty-logo.webp`

No cambies el nombre del archivo ni lo metas dentro de una carpeta.
