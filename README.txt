CÓMO ABRIRLO EN VISUAL STUDIO CODE
-----------------------------------
1. Descomprime la carpeta PALOMITOPTY_WEB.
2. En Visual Studio Code selecciona:
   Archivo > Abrir carpeta...
3. Selecciona la carpeta PALOMITOPTY_WEB.
4. Abre index.html.
5. Si tienes la extensión "Live Server", haz clic derecho sobre index.html
   y selecciona "Open with Live Server".
